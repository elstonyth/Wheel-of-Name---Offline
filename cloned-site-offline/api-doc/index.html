About the API

Do you want to create shared wheels from your software instead of through the Wheel of Names website? With the API you can for example:

  • Automate creation of wheels from lists of people or things.
  • Create wheels based on dynamic events, like who is currently logged in to your system.
  • Create wheels based on your database content.

If that sounds interesting, this API is for you. It is an HTTP API and if you have integrated with REST-like APIs in the past, you will feel right at home.

Grab an API key on the right, head over to the API documentation, and try it out now!

The API may change. To learn about changes before they happen, follow the API Updates channel on our Discord server. Here is how:

  1. Go to our Discord server.
  2. Click Channels & Roles near the top of the left-hand column.
  3. Click API updates.
  4. Now you have access to the api-discussion channel. Check in on the channel every now and then, or turn on notifications for it.
