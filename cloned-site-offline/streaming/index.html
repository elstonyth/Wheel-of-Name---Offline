Instructions
  1. In OBS: Studio (or similar software, such as Streamlabs), create a new "Browser" source in the sources list of your scene.
  2. Paste the link above into the URL field. Set the width and height to 700x700 for the best clarity.
  3. To spin the wheel, click the "Interact" button while the browser source is selected, then click on the wheel in the newly opened window.
  4. To update the wheel displayed in your stream, make the changes you need (like adding entries) and click the "Save" button on this page. Then with the browser source selected in OBS: Studio, click the "Refresh" button.
